# наши полгода 💙

Приглашение на виртуальное свидание 24 ноября. Чистый HTML/CSS/JS, без сборки.

Живая версия: https://m1ndl0ss.github.io/24/

## Что где лежит

| файл | зачем |
|---|---|
| `config.js` | все тексты, время, список фото, ссылка для Telegram |
| `index.html` | разметка шести экранов |
| `style.css` | внешний вид и анимации |
| `script.js` | логика: печать текста, галерея, музыка, конфетти |
| `photos/` | фото галереи (`1.jpg`, `2.jpg`, …) и `final.jpg` для финала |
| `audio/song.mp3` | музыка, включается по кнопке «yes» и играет по кругу |
| `tools/prepare_photos.py` | подготовка новых фото |

## Поменять текст, время или ссылку

Всё в `config.js`. Время галереи — `photoSeconds` (сейчас 2 секунды на кадр),
слоты времени — `time.from`, `time.to`, `time.stepMinutes`.

Экран с цифрами считает дни от `stats.startDate` (сейчас 2026-05-24) до
сегодня — поменяй дату, если начало другое.

## Поменять фото

1. Кинь новые файлы в корень репозитория или в `photos/`, назови их по порядку:
   `1.jpg`, `2.jpg`, … и `final.jpg` для последнего экрана.
2. Запусти `python tools/prepare_photos.py` — он выправит поворот по EXIF,
   уменьшит до 1200px по длинной стороне, пережмёт в JPG, а оригиналы
   сложит в `photos/originals/` (эта папка в `.gitignore`).
3. Скопируй напечатанный список в `config.js`.

Для HEIC с айфона нужен один раз `pip install pillow-heif`.

## Поменять музыку

Положи файл в `audio/` под именем `song.mp3`.

## Залить изменения

```bash
git add -A
git commit -m "что поменял"
git push
```

GitHub Pages обновится сам за минуту-две. Если видно старое — обнови страницу
с Ctrl+Shift+R (на телефоне — вкладка в режиме инкогнито).
